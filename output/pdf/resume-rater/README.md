# Resume Rater sample data

All candidates, employers, contact details, and results in these files are fictional. The example email addresses use the reserved .invalid domain.

## Try the workflow

1. Open Resume Rater and start a job workspace titled Senior Backend Engineer.
2. Copy the contents of sample-job-posting.txt into the Job Posting field.
3. Review and approve the suggested rubric.
4. Upload all three candidate PDF files together.
5. Wait for assessments, then compare the evidence and reports.

## Intended sample pattern

- **Candidate A:** Direct match for production Python services, APIs, PostgreSQL, reliability, async jobs, and mentoring.
- **Candidate B:** Relevant Python, REST, PostgreSQL, and testing experience, with less evidence of production reliability and async systems.
- **Candidate C:** Useful Python and SQL experience, but limited production API ownership.

The broad expected order is A, B, then C. Scores and order can vary with the approved rubric and local model. Use the set to exercise the workflow, not to validate hiring accuracy or fairness.
